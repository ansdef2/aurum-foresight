# Этап 1. Комплект для сдачи

Передайте два файла:

1. `docs/stage1_training_result.pdf` с итогами обучения.
2. `stage1_code_tables_logs.zip` с кодом и материалами прогона. Копия PDF также лежит в архиве.

В архиве находятся код приложения и скриптов, тесты, таблица из задания, негативные примеры, три CSV с признаками, поисковые формулировки, обученная модель, отчёты, рисунки и журналы запусков. `weak_signals.db` содержит ответы открытых источников, использованные при сборе. В базе нет заданий пользователя и журналов вызовов языковых моделей.

Дата признаков: 28.09.2026. Основной CSV содержит 223 строки. Каждый из двух дополнительных CSV содержит 24 строки. Ошибок источников в итоговых таблицах нет.

Итоговая модель использует C=0,05 и порог 0,60. Валидация по ТЗ дала Accuracy 80,4%, Precision 77,0%, Recall 80,3% и F1 78,6%. При проверке на новой теме получены 78,9%, 76,2%, 77,0% и 76,6% соответственно. Четыре запуска записаны в `docs/experiment_log.md`.

Знаки восьми весов заданы при обучении. Вес доли массовых СМИ равен −0,001 и почти не влияет на решение. Другие поисковые фразы меняли часть решений. Сквозной поиск кандидатов на этом этапе не проверялся.

Для проверки кода установите зависимости из `requirements.txt`, затем выполните `python -m pytest -q`. В этом прогоне прошли 18 тестов.
