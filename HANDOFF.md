## Текст слайда «Техническая суть решения»
Заголовок: Как система отличает слабый сигнал от шума
- Конвейер: запрос -> LLM разбирает направление на подобласти -> сбор OpenAlex, arXiv, Google News (RU/EN), GitHub, Wikipedia -> LLM извлекает кандидатов -> склейка русских и английских синонимов -> детектор -> ТОП-15 + список отклонённых с причиной.
- Детектор без LLM: 16 признаков (рост публикаций по гамма-пуассоновской оценке, всплески новостей по автомату Клейнберга, «лестница зрелости» наука -> код -> деньги -> СМИ -> энциклопедия, независимость источников) и логистическая регрессия.
- Интерпретируемость: вклад каждого признака = вес × значение, показывается в отчёте как «ключевые предикторы».
- Источники ранжируются A–D; пресс-релизы и агрегаторы не могут быть единственным основанием, уверенность снижается ×0,7.
- LLM только извлекает факты и пишет тексты по найденным источникам; решение принимает детектор. Каждый вызов модели логируется (`/api/jobs/{id}/llm`).
- Честная оценка: leave-one-theme-out; датасет физически не попадает в образ стенда.
- Стек: Python, FastAPI, PostgreSQL, scikit-learn, NumPy, GigaChat, Docker Compose, Caddy (HTTPS).
