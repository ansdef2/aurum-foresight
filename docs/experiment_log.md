# Журнал экспериментов детектора

Цель: Accuracy, Precision, Recall и F1 в строке «Валидация по ТЗ» не ниже 75%.
Проверка: пять стратифицированных фолдов и три повтора. Дата признаков: `AS_OF_DATE=2026-09-28`.
Каждая строка ниже описывает один запуск `python -m scripts.experiments`. Всего допустимо пять запусков.

1. Базовая модель: C=1, порог 0,50. Accuracy 78,0%, Precision 71,8%, Recall 84,0%, F1 77,4%. Ошибок источников нет. Precision ниже 75%.
2. Порог 0,64 при C=1. Accuracy 78,6%, Precision 75,7%, Recall 77,0%, F1 76,4%. Требование выполнено, но в LOTO Recall 70,0%.
3. C=0,05 и порог 0,60. Accuracy 80,7%, Precision 77,1%, Recall 81,0%, F1 79,0%. LOTO: 79,8%, 76,7%, 79,0%, 77,8%. Вес массовых СМИ +0,111.
4. Ограничены знаки восьми весов. C=0,05, порог 0,60. Accuracy 80,4%, Precision 77,0%, Recall 80,3%, F1 78,6%. LOTO: 78,9%, 76,2%, 77,0%, 76,6%. Вес СМИ −0,001.
